# 원본 보존

사용자 제공 ZIP `/Users/hajiseung/Downloads/tiny project.zip`, PDF `/Users/hajiseung/Desktop/35016389.pdf`를 바이트 그대로 복사했다. MANIFEST.json은 전체 ZIP 멤버와 첨부물 SHA-256 및 원래 경로를 기록한다. SHA256SUMS는 공개 보존본을 검증한다.

`source/`는 원본 소스·Quartus 설정·기존 보고서(바이트 변경 없음). 캐시·SOF 등 전체 아카이브와 PDF는 `private/`에 보존하며 Git에서 제외한다. PDF 공개 배포 권한은 미확인이다. 보존 후 이 디렉터리의 파일은 수정하지 않는다.

기존 테스트벤치, SDC, ROM/include/IP, 별도 보고서 문서, 보드 사진·영상은 제공 자료에서 찾지 못했다. Quartus 출력 보고서는 확보했다.
