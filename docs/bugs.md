# 버그와 근거

원본 무수정 Icarus 실행 로그는 `evidence/baseline-*.log`, 파형은 `make baseline`으로 재생성한다. 기능 테스트는 분주 출력만 테스트 클록으로 강제한다. 금액 상수는 PDF의 십진 가격과 일치하며 가격 버그는 없다.

| ID | 요구사항 | 원본 위치 | 재현 / 기대 / 실제 | 원인 / 최소 수정 | 회귀 / 결과 |
|---|---|---|---|---|---|
| B01 | R01, R05 | TINYPROJECT reset 블록 | reset → Ticket=0 기대, X 관측 | Ticket reset 누락 → 0 대입 | reset / 실패 후 통과 |
| B02 | R07 | LAB4c S7 | 상태 주입 후 IN → S1 기대, S7 유지 | 조건 뒤 무조건 S7 덮어쓰기 → else | fsm / 실패 후 통과 |
| B03 | R02 | LAB4c S0,S5 | SW0 긴 누름 → 500 기대, 3500 | IN 레벨 재사용 → 누름 이벤트 | held / 실패 후 통과 |
| B04 | R04 | bin7seg 1 | 1700 표시 → 1의 b,c 점등 기대, e,f 점등 | 잘못된 상수 → 1001111 | digit1 / 실패 후 통과 |
| B05 | R05,R07 | Ticket 갱신 / S4 | 5000 투입 후 3300 구매 → 다음 선택까지 LED=1 기대, 0 | prt=0 분기에서 조기 소등 → 선택 변경까지 유지 | ticket / 실패 후 통과 |
| B06 | R04 | 최상위 포트 | HEX4 출력 요구, 포트 없음 | 상위 0 자리 연결 추가 | 최종 보드 테스트에서 검증 예정 |

B02는 원본 정상 거래에서는 B05 때문에 S6/S7에 도달하지 못했다. 원본에서 주입 없이 FSM 정체가 발생했다고 주장하지 않는다. fsm은 분리한 전이 단위 테스트이다.

첫 테스트벤치의 SystemVerilog string case에서 Icarus 13.0 컴파일러 assertion을 만나 packed 문자열로 교체했다. 원본 RTL 호환성 수정은 없으며 도구 오류 로그를 별도 보존했다. 실패 기록 이전 테스트 준비 과정에서 SW0 기대값 오독을 PDF와 대조해 500으로 바로잡았고 이후 기대값은 변경하지 않았다.
